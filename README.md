# 🛍️ E-Shop

E-Shop is a responsive e-commerce website built using **HTML, CSS, JavaScript, and Bootstrap**.  
The project provides a simple and user-friendly online shopping interface.

## 🚀 Features

- 🏠 Responsive home page
- 🛒 E-commerce shopping interface
- 📦 Product listing
- 🔍 Product interaction using JavaScript
- 📱 Mobile-friendly responsive design
- 🎨 Clean and modern UI
- ⚡ Dynamic functionality using JavaScript
- 🧩 Bootstrap components and responsive grid system

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Git & GitHub
